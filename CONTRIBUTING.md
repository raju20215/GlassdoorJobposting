# Contributing to Glassdoor Job Postings EDA

Welcome to the Glassdoor Job Postings EDA project! I appreciate your interest in contributing. This document provides guidelines for contributing to this repository.

## 🤝 How to Contribute

### Reporting Bugs
If you find an issue in the data analysis or code, please create a new issue. Be sure to include:
*   A clear, descriptive title.
*   Description of the error or discrepancy.
*   Standard output or error messages.

### Suggesting Enhancements
Have an idea to improve the analysis or add new visualizations?
*   Open an issue with the tag `enhancement`.
*   Clearly explain the new analysis or plot.
*   Explain why it would be useful (e.g., "Adding a word cloud for soft skills would help identify non-technical requirements").

### Submitting Pull Requests
1.  **Fork the repository** to your own GitHub account.
2.  **Clone the project** to your machine.
3.  **Create a new branch** for your feature or fix (`git checkout -b feature/NewAnalysis`).
4.  **Commit your changes** (`git commit -m 'Add soft skills word cloud'`).
5.  **Push to the branch** (`git push origin feature/NewAnalysis`).
6.  **Open a Pull Request** against the `main` branch.

## 💻 Coding Standards
*   Follow PEP 8 style guidelines for Python code.
*   Ensure the notebook is clean (clear outputs before committing if possible, or ensure outputs are helpful).
*   Comment your code to explain complex data transformations.

Thank you for your contributions!
